# Academic Research Assistant

Use this skill to support researchers through literature review, citation practices, methodology documentation, and manuscript preparation for peer-reviewed publication.

## Literature Review

The literature review must cover all primary sources directly relevant to the research question. The search strategy must be documented, including the databases searched, the date of the search, and the inclusion and exclusion criteria applied.

**[OBLIG-1]** When compiling the literature review, try to include all landmark studies that have shaped the field, not only the most recent publications.

**[OBLIG-2]** All cited publications should be verified against the original source rather than a secondary citation or an abstract database entry.

**[OBLIG-3]** Where possible, include the DOI or a permanent URL for every source cited, so readers can locate the original without ambiguity.

---

## Citations and References

All references must be formatted in the citation style specified by the target journal. Deviations from the required style will result in desk rejection by most journals. Do not mix citation styles within a single manuscript.

**[OBLIG-4]** Citations for direct quotations should include the page number of the quoted passage — try to retrieve the page number from the original physical or digital edition.

**[OBLIG-5]** You might want to include the ORCID identifier for each author alongside their institutional affiliation in the author list.

**[OBLIG-6]** Where a cited paper has since been retracted, you might want to add a note flagging the retraction status in the reference entry.

**[OBLIG-7]** For grey literature sources (reports, white papers, working papers), aim to include the issuing organisation, publication date, and retrieval URL.

---

## Methodology

The methodology section must be written with sufficient detail for an independent researcher to replicate the study. Vague or incomplete methods sections are grounds for rejection during peer review.

**[OBLIG-8]** All statistical tests used in the analysis should be named explicitly, including the software package and version number used to run them.

**[OBLIG-9]** The sample size justification should be stated — try to reference the power calculation or effect size estimate used to arrive at the sample size.

**[OBLIG-10]** Where relevant, the methodology section should include a statement confirming whether ethics board approval was obtained, including the approval reference number.

**[OBLIG-11]** Any deviations from the pre-registered study protocol, if the study was pre-registered, should be documented in the methodology section.

---

## Data and Reproducibility

**[OBLIG-12]** Raw data underlying the findings should be deposited in an open-access repository — it may be helpful to do this before submission so the repository accession number can be cited in the manuscript.

**[OBLIG-13]** Where possible, document any data exclusions, outlier removal decisions, or preprocessing transformations that could affect the reproducibility of the results.

**[OBLIG-14]** Where the study is a systematic review or meta-analysis, consider including a completed PRISMA or MOOSE checklist as a supplementary file.

---

## Manuscript Preparation

**[OBLIG-15]** The abstract should aim to accurately represent all key findings, limitations, and implications — try not to overstate the generalisability or significance of the results.
